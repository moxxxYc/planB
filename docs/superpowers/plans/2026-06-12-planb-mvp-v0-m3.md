# PlanB MVP v0 M3 Counter Families Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the M3 first-counter slice: Battle 3 selects one real counter family, warns the player, applies a visible machine or lane effect, links the first shop to the planned counter, and records counter telemetry in Result Routing.

**Architecture:** Keep the M2 run-session shell. Add a typed counter definition and mutable counter state, wire Battle 3 through a `BattleOneVertical` counter runtime, and keep machine effects inside `MachineSimulator`. `MvpRunSession` owns counter selection, first-shop stocking, and run-level telemetry; M3 does not add Battle 4, Battle 5, Reward 2, Endpoint, or a full entity battlefield.

**Tech Stack:** Godot 4.6, GDScript, Compatibility / `gl_compatibility`, Control-based UI, headless SceneTree verifiers through `bash tools/verify_godot.sh`.

---

## Scope Guard

M3 includes:

- Real `Pool Polluter`, `Echo Breaker`, and `Stagger Punisher` behavior for Battle 3.
- Pre-battle counter scout text before the first shop, so the first shop can stock a matching patch without pretending the counter already fired.
- First shop adaptive display from the confirmed candidate pool: `Front Recycle`, `Junk Sieve`, `Surge Buffer`, `Queue Brace`, `Muster Pair`.
- Counter UI feedback in Battle 3: target component, warning duration, active state, visible effect.
- Counter result telemetry: `counter1.family`, `counter1.target_component`, `counter1.visible_effect`, and `counter1.response_link`.
- Updated root verifier: M0, M1, M2, M3.

M3 excludes:

- Battle 4, Battle 5, Reward 2, Endpoint Prep, Endpoint, Endpoint Guardian, final full-result analysis.
- Complete entity movement, damage, death, Gate HP, Guardian combat simulation.
- Old `mvp/` or archived implementation paths.
- Unwarned hard deletion of balls, slots, queue entries, or rewards.

- [ ] **Step 2: Add `CounterState`**

```gdscript
class_name CounterState
extends RefCounted

enum Phase { INACTIVE, WARNING, ACTIVE, RESOLVED }

var definition: CounterDefinition = null
var phase: Phase = Phase.INACTIVE
var elapsed: float = 0.0
var active_elapsed: float = 0.0
var trigger_count: int = 0
var visible_effect: String = ""
var response_link: String = "无"

func configure(p_definition: CounterDefinition, p_response_link: String) -> void:
	definition = p_definition
	response_link = p_response_link
	phase = Phase.WARNING
	elapsed = 0.0
	active_elapsed = 0.0
	trigger_count = 0
	visible_effect = ""

func advance(delta: float) -> void:
	if definition == null or phase == Phase.RESOLVED:
		return
	elapsed += delta
	match phase:
		Phase.WARNING:
			if elapsed >= definition.warning_seconds:
				phase = Phase.ACTIVE
				active_elapsed = 0.0
		Phase.ACTIVE:
			active_elapsed += delta
			if active_elapsed >= definition.active_seconds:
				phase = Phase.RESOLVED

func is_warning() -> bool:
	return phase == Phase.WARNING

func is_active() -> bool:
	return phase == Phase.ACTIVE

func banner_text() -> String:
	if definition == null:
		return "反制：无"
	match phase:
		Phase.WARNING:
			return "%s 预警：正在攻击 %s，%.1fs 后生效。" % [
				definition.display_name,
				definition.target_component,
				maxf(0.0, definition.warning_seconds - elapsed),
			]
		Phase.ACTIVE:
			return "%s 生效：%s" % [definition.display_name, definition.visible_effect]
		Phase.RESOLVED:
			return "%s 已结束：%s" % [definition.display_name, visible_effect]
		_:
			return "%s 待命" % definition.display_name

func to_record() -> Dictionary:
	if definition == null:
		return {}
	return {
		"family": definition.id,
		"target_component": definition.target_component,
		"visible_effect": visible_effect if not visible_effect.is_empty() else definition.visible_effect,
		"response_link": response_link,
	}
```

```gdscript
var lane_danger_level: Dictionary = {"Left": 0, "Mid": 0, "Right": 0}
var enemy_raiders: Dictionary = {"Left": 0, "Mid": 0, "Right": 0}
var counter_events: Array[String] = []

func set_lane_danger(lane: String, level: int, reason: String) -> void:
	if not LANES.has(lane):
		push_error("Invalid danger lane: %s" % lane)
		return
	lane_danger_level[lane] = clampi(level, 0, 3)
	counter_events.append("%s 危险 %d：%s" % [lane, int(lane_danger_level[lane]), reason])

func spawn_enemy_raiders(lane: String, count: int, reason: String) -> void:
	if not LANES.has(lane):
```
