# Phase 2 Known Issues

本文记录 Phase 2 controlled external playtest 前已知限制。它不是公开 demo 缺陷清单。

## 已知限制

- Phase 2 只验证可读性闭环，不代表完整 MVP 已完成。
- 内容扩展不在范围内：没有新增种族、敌人、反制家族、Guardian kits、事件池或奖励系统。
- 数值仍是可读性验证用 first-pass，不是长期平衡定版。
- `docs/ball-machine-physical.md` 仍是 MVP v0 实现输入候选，不是长期 canon。
- 结果页 recap 可以先使用稳定短文本，不代表最终 UI 文案。
- Counter clarity 只解释既有 `Pool Polluter`、`Echo Breaker`、`Stagger Punisher`，不新增系统。

## Playtest 时不要解释

- 不要提前解释完整 GDD。
- 不要解释 debug scene 或 verifier 输出。
- 不要把不可读问题归因于“内容还没做完”。Phase 2 要验证的是现有 playable session 能否自解释。
