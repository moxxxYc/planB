# planB 概念一页纸

**日期：** 2026-06-08
**状态：** 当前概念方向，非实现计划。

## 核心幻想

玩家像调校一台会出兵的物理战争机器：本局逐步判断该放大 `Launch / Tuning / Unit` 哪条轴，然后在三路自动战斗中看到这个选择变成持续流、重复重击或批量冲锋。

这不是直接操作单位的幻想，也不是单纯买数值的幻想。主要情绪是：

> 我看懂了这局机器想走哪条路，我继续加码，然后战场真的变了。

## 核心循环

观察球机和战场信号 -> 选择强化、转向或补洞 -> 用奖励、商店、事件和种族规则改变机器组件 -> 战斗中选择 `Deploy Lane` -> 看单位是否在目标路线上赢下接战并推进。

## 机械差异点

球机不是分数机器，也不是背景生产表。它是构筑引擎：

- `Launch` 决定输入量、发射节奏、路线倾向、回流和污染压力。
- `Tuning` 决定球进入 Unit 前的转换质量。
- `Unit` 决定槽位进度、队列、部署节奏和批量出兵。

同样是“前线变强”，三条轴应该读起来不同：

- `Launch` 像稳定补兵和持续压线。
- `Tuning` 像少数高价值结算造成重复重击。
- `Unit` 像蓄力后的成批冲锋。

## 目标玩家

- 主要玩家：喜欢系统构筑、Roguelite 路线选择、自动战斗结果复盘的玩家。
- 主要玩家：喜欢 Castle Fight 类自动出兵、兵线推进、宏观构筑而非微操的玩家。
- 次要玩家：喜欢物理球路和可视化机器反馈的玩家。
- 不服务：高频动作玩家、RTS 微操玩家、PVP / 排位玩家、纯物理分数玩家、长期在线服务型玩家。

## 平台与商业模式

- 平台：PC / 桌面优先。
- 输入：应能鼠标操作。
- 正式单局目标：45-60 分钟。
- 第一版 MVP：15-20 分钟短局。
- 商业模式：买断制，可考虑 DLC。不做当前 F2P / IAP 设计。

## 当前核心系统

- 三仓机器：`Launch / Tuning / Unit`。
- Tuning 槽：`Gate / Prime / Echo / Surge`。
- 战场：两端基地圈、三条固定路径、自动单位接战。
- 战中输入：选择当前 `Deploy Lane`，不操作已部署单位。
- Guardian：固定基地对象，同时可作为开局构筑锚点。
- 经济：`Gold / 金币` 主要来自战后结算。

## 当前最大风险

玩家可能看不出“机器轴改变了战场”。如果玩家只看到球和单位都在自动动，但说不出哪条轴起作用，项目会退化成噪音。

## 当前设计重点

基础机制已整理到可以进入第一种族设计。第一种族方向已确认 Hive，并采用 `Caste Hive`：巢群分工阶级，用 4 个 `Unit slot` 表达从低承诺到高承诺的单位职责梯度。当前 4 槽单位原型是：Slot 1 `短牙虫` 快速接线和稳定补线，Slot 2 `盾壳虫` 守线抗压，Slot 3 `酸囊虫` 用短程酸液弹道和命中点小范围溅射破僵持，Slot 4 `碾壳兽` 慢到场并用同一路线接战点横扫重击翻线。两个 Hive `Player Guardian` 为 `巢脉母` 和 `酸冠母`，分别偏 `Launch` 持续压线和 `Tuning` 破点爆发；`巢脉母` 规则目标为 `Launch.Recycle / Launch.Pool`，表现为巢脉回流 / 巢脉输送；`酸冠母` 规则目标为 `Tuning.Prime`，表现为酸冠入槽和 Prime 命中反馈。Hive MVP 机器包装采用视觉区分，不为通用机器轴和基础槽位设置 Hive 副名。Slot 3 是 MVP 初期验证半远程单位读法的目标。4 个单位的 MVP 工作名、占位剪影、轻技能深度和第一版攻击几何已确认，两个 Guardian 的身份、轴倾向、技能结构、技能方向、战术技能目标优先级、`酸冠反喷` 第一版范围、战略技能目标、战略 operation 和第一版 `Guardian Contract` 已确认；最终美术资源和最终数值仍未定。`Infection Hive` / 感染、孵化、寄生方向不进入 MVP 第一种族 baseline，保留给未来其他种族或后续大内容。

1. 完整 MVP 实现输入边界。
2. Hive 对通用球机的最终视觉表现、反馈语言和构筑词汇。
3. 如实现需要，再收束 `Unit.Slot.Exposure Gate` 暴露插值方式。
4. 继续验证玩家能否读出三条机器轴如何改变战场。
