# Deploy Lane UI 与路线危险提示

**最后更新：** 2026-06-10
**仓库状态：** 文档主导，MVP v0 实现已在 `mvp/` 启动；本文不作为代码状态证明。
**权威范围：** `Deploy Lane` 的直接选路、选中高亮、路线危险提示、队列落点反馈。

本文只定义玩家如何选择部署路线，以及系统如何提示路线危险。机器队列见 `docs/machine-warehouses.md`，战场结算见 `docs/battlefield-rules.md`，敌人波次见 `docs/enemy-rules.md`。

## 1. 目标

`Deploy Lane` 的目标是让玩家直接决定后续单位从哪条路线出兵：

- 玩家直接点击战场上的 `Left / Mid / Right` 路线。
- 点到哪条路，哪条路就成为当前出兵路线。
- 当前选中路线高亮显示。
- 后续队列条目部署时读取当前选中路线。
- 机器队列通过 `Queue / Deploy Bridge` 指向当前选中路线的玩家侧出兵口。

它不是救命按钮，不是 RTS 微操，不是自动最优推荐。

## 2. 基础交互

第一版使用战场路线本体作为可点击区域。

| 操作 | 结果 |
|---|---|
| 点击 `Left` 路线 | 当前出兵路线变为 `Left`。 |
| 点击 `Mid` 路线 | 当前出兵路线变为 `Mid`。 |
| 点击 `Right` 路线 | 当前出兵路线变为 `Right`。 |
| 重复点击当前路线 | 无额外效果，只保持选中。 |

基础规则：

- 战斗开始默认选中 `Mid`。
- 点击路线立即生效。
- 没有切路冷却。
- 没有待切路线。
- 没有独立三按钮面板。
- 不做自动选路。
- 不做“推荐路线”按钮。

## 3. 选中高亮

当前选中路线必须清楚，但不能盖过战场本身。

第一版高亮：

- 选中路线边缘显示玩家色描边。
- 选中路线入口和出口各有一个小型路线标记。
- 当前路线可以有轻微流动方向线，表示后续单位会从这里出兵。
- 非选中路线保持正常可读，不变暗到看不清战斗。

选中高亮和路线危险提示必须分层：

| 类型 | 语义 | 视觉方向 |
|---|---|---|
| 选中高亮 | 我当前会从这里出兵。 | 玩家色、稳定、持续。 |
| 危险提示 | 这条路即将或正在出事。 | 敌方色、脉冲、短时。 |

如果玩家分不清“我选中了这路”和“这路危险”，说明 UI 失败。

## 4. 部署读取规则

普通队列条目在部署节拍读取当前选中路线。

结算顺序：

1. 玩家点击路线，更新当前 `Deploy Lane`。
2. 队列部署节拍到达。
3. 队列条目读取当前 `Deploy Lane`。
4. 单位从对应路线的玩家侧入口出生。

这意味着：

- 点击后不会立刻生成单位。
- 点击只改变后续部署位置。
- 点击不改变单位类型、单位数量、槽位进度、队列速度。
- 已部署单位不受后续点击影响。
- 玩家侧入口不是 Guardian。三条入口位于玩家基地圈连接战场路径的一侧，并与 `Player Guardian` 保持基地缓冲区距离。

## 5. 批量部署

基础规则不做批量锁路。

如果某个队列条目一次性生成多个单位，这些单位在同一部署节拍读取同一个当前路线，并一起从该路出生。

如果某个命名规则让批量分多个部署节拍释放，每个部署节拍各自读取当时的当前路线。以后如果某个种族、奖励或技能需要“整批锁路”，必须作为命名规则单独声明，不进入基础规则。

失败信号：

- 玩家以为点击路线会拆分已经出生的单位。
- 玩家以为点击路线会改变当前战场单位目标。
- 玩家看不出下一次队列部署会从哪一路出生。

## 6. 队列落点反馈

`Deploy Lane` UI 必须显示队列与路线的关系。

第一版反馈：

| 反馈 | 读法 |
|---|---|
| 当前路线高亮 | 下一次部署节拍会从哪一路出兵。 |
| 队列首条落点标记 | 队列第一个条目将去当前路线。 |
| Bridge 到出兵口短连线 | 机器队列正在连接当前选中出兵口，不是连接 Guardian。 |
| 出生口短闪 | 单位实际出生时确认落点。 |

队列预览：

- 显示接下来 3 个队列条目即可。
- 每个预览条目使用当前路线小标记。
- 不显示完整未来模拟。
- 不做路线最优预测。

Bridge 规则：

- `Queue / Deploy Bridge` 位于机器和战场之间，只负责显示队列到路线的落点关系。
- Bridge 的视觉指向必须落在当前选中路线的玩家侧出兵口。
- Bridge 不指向 `Player Guardian`，不指向战场中心，也不解释为额外出兵系统。
- 选中路线变化时，Bridge 的当前路线标记和出兵口连线随之更新。

## 7. 路线危险等级

路线危险提示只来自可见战场状态和已公开的波次/反制预警，不读隐藏压力值。

第一版四档：

| 等级 | 名称 | 触发条件 | UI 表现 |
|---|---|---|---|
| 0 | 安全 | 没有已知近期威胁。 | 正常路线状态。 |
| 1 | 压力 | 该路有敌人波次预告，或敌人预计 8-12s 内进入接战。 | 路线旁出现小型敌方色预告点。 |
| 2 | 破门风险 | 敌人接近玩家侧 Gate，或玩家侧 Gate 预计 6s 内受击。 | 路线边缘敌方色脉冲，玩家侧 Gate 轻闪。 |
| 3 | 漏兵 / 入侵 | 玩家侧 Gate 正在受击、已破，或敌人进入玩家基地圈。 | 强警示，路线和基地圈同时闪烁，一次性音效。 |

危险等级只提示状态，不自动切路。

## 8. 路线危险来源

危险提示来自三类来源：

1. 敌人波次预告
   `docs/enemy-rules.md` 中的主压路线至少提前 3s 暴露，但 UI 应尽量在 6-8s 前给出等级 1 压力提示。

2. 战场实时状态
   根据可见敌人位置、玩家侧 Gate HP、基地圈入侵状态更新。

3. 反制预警
   `Stagger Punisher` 的危险路线预告直接把该路提升到至少等级 2。

禁止来源：

- 隐藏胜率。
- 隐藏压力值。
- AI 推荐最优路线。
- 只靠文字告诉玩家“该去左路”。

## 9. 与 Stagger Punisher 的关系

`Stagger Punisher` 惩罚长时间无部署，而不是惩罚选路。

UI 规则：

- 当 Unit 队列连续 3s 没有部署，显示空档预警。
- 到 4s 触发 `Stagger Punisher` 监测条件。
- Stagger 路线预告显示 3s。
- 被选中的危险路线提升到等级 2。
- 如果队列恢复部署，空档预警消失，但已经公开的 Stagger 突袭不取消，除非具体敌人规则另写。

玩家读法应该是“我等大批太久，被突袭了”，不是“游戏随机刷怪”。

## 10. 新手引导最小范围

首次进入战斗只教三件事：

- 直接点击战场路线可以选择出兵路线。
- 被选中的路线会高亮。
- 路线出现敌方色提示表示该路即将有危险。

不要在新手引导中解释：

- 所有危险等级。
- Stagger Punisher。
- 队列预览的完整细节。

这些通过第二、第三场战斗逐步暴露。

## 11. 失败模式

- 玩家以为点路线会立刻造兵。
- 玩家以为点路线能控制已经出场的单位。
- 玩家不知道下一批兵会去哪一路。
- 玩家以为队列从 Guardian 身上出兵。
- 玩家以为 Bridge 本身是第四个机器仓或独立操作面板。
- 玩家以为点路线改变了单位产出。
- 危险提示像隐藏推荐，玩家只是照着亮灯点。
- 选中高亮和危险提示混在一起。
- 三路压力变成打地鼠，玩家只盯路线不看球机。
- Stagger Punisher 看起来像随机刷怪。
